# Zig Built In Functions - compileLog

## Abstract
 This function prints the arguments passed to it at compile-time.

To prevent accidentally leaving compile log statements in a codebase, a compilation error is added to the build,
pointing to the compile log statement. This error prevents code from being generated, but does not otherwise interfere
with analysis.

This function can be used to do "printf debugging" on compile-time executing code.
