# Zig Syntax Struct

## Abstract

Defining a Struct in Zig:

```zig
const ExampleStruct = struct {
    x: u64
    y: i64
    z: bool
}
```

Instantiating a struct in Zig:

```zig
const exampleStruct = ExampleStruct{
    .x = 1,
    .y = -4,
    .z = false
}
```
