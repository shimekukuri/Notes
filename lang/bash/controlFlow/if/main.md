# Bash Control Flow - If

## Abstract
if ... ; then ... fi: The standard structure for conditional statements in Bash.
[: Also known as the test command. it evaluates the expression inside it and returns an exit status (0 for true,
non-zero for false).

-d: A unary operator (flag) that specifically tests if the operand exists and is a directory.

"$d": The variable being checked.

$d: References the value of the variable named d.

Double Quotes (" "): Critically important to prevent errors if the directory name contains spaces or special characters.

]: The closing argument required by the [ command.
