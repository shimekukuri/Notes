# C Sharp Extension Methods

## Abstract
Essentially you can define methods onto an existing class be creating this specialized extension class when you bring
this specialized extension class into scope it appends onto that class these additoinal methods.

[[programming-opinions]]
Honestly kind of a neat idea, becuase you don't have to modify the existing class and change the implementation of the
base class to adhear to these addtional methods. Although just also begs the question as always why don't we just use
some functions that take these extra parameters. The intrigal tying of data and the methods on it creatins this web
of ways to manage the relation between data and what consumes it. I would just argue that maybe that they aren't
really meant to be tied together this closely where by we cannot seperate one from the other without some safisticated
model DTO nonsense and really all we need was some objects and some fucntions to do something with those objects.
