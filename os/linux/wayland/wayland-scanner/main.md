# Linux Wayland - wayland-scanner

## Abstract
The "wayland-scanner" tool is used to process these XML files and generate code from them. The most common
implementation is the one you're examining now, and it can be used to generate C headers & glue code from XML files
like wayland.xml. Other scanners exist for other programming languages, notably wayland-rs (Rust), waymonad-scanner
(Haskell), and more.
