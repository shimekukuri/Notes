# Clayton C# Launch Development

## Abstract
add this to the launch settings json:
```json
"Development": {
    "commandName": "Project",
    "launchBrowser": true,
    "applicationUrl": "https://localhost:5001;http://localhost:5000",
    "launchUrl": "swagger",
    "environmentVariables": {
        "ASPNETCORE_ENVIRONMENT": "Development"
    }
}

```
