# Clayton Homebase Inspections Confluence Legacy Utility API

## Abstract
Legacy Utility API is an on-prem API used by modern Remarketing apps to access legacy data and services.  Intended to
be temporary until equivalent modernized APIs are deployed.

This API is only intended for use by Remarketing apps.  Please contact the Remarketing Tech Team if access is
required.
