# Clayton Databases

## Abstract
Clayton uses many different databases that align to different business needs, all of them run via microsoft sql server.
They use [[flyway]] for migration and also some kind of powershell scripts in order to scaffold out the local instances
of the databasees.

There is possible room for imporovment in the sense that it could possibly be moved to [[containers]] with some type of
orchestration.
