# RAM-3744

## Description
As a Task Tracker user I need the ability to give more information to the assignee of a task about the Utility tasks,
so that they can work more effeciently.

(This is basically the same idea we did for "Pay Invoice" BUT the new field is not required)

## AC
Utility Tasks need to have the following fields added to the create task field:

Utility Name
Meter Number
THESE ARE NOT REQUIRED
