# React Concepts Forward Ref

## Abstract
When creating a ref and using it you have to take special care if you are going to use that ref that attatches to
something that is inside a component. You have to use a function called forward ref that then take sthe ref from the
outside and "forwards" it into the component to where it needs to go. See the how to for an example.
